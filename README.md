# QA Playwright Automation Framework

A test automation framework built with **Playwright** and **TypeScript**, using the **Page Object Model (POM)** design pattern. This project automates core e-commerce flows (login, cart, checkout) against [saucedemo.com](https://www.saucedemo.com/), a public demo site for QA practice.

## Tech Stack
- **Playwright** — browser automation
- **TypeScript** — language
- **Page Object Model** — design pattern for maintainable tests
- **Git/GitHub** — version control
